TURTLEBOT3 LINUX MINI QUEST — ROUND 2
=====================================

Misi:
Temukan file treasure.txt menggunakan petunjuk di dalam file-file teks.

Mulai dari:
  cd ~/treasure_hunt_round2
  pwd
  ls

Perintah yang boleh digunakan:
  pwd       - melihat lokasi folder saat ini
  ls        - melihat isi folder
  cd NAMA   - masuk ke folder
  cat FILE  - membaca isi file

Aturan:
1. Jangan gunakan find, locate, grep, atau pencarian otomatis lainnya.
2. Ikuti petunjuk dengan membaca isi file.
3. Setelah menemukan treasure.txt, baca isinya dengan cat.
4. Laporkan kode misi kepada instruktur dan jelaskan fungsi pwd, ls, cd, dan cat.

Catatan instruktur:
- Struktur dan jalur petunjuk ronde ini berbeda dari ronde pertama.
- Untuk kompetisi yang adil, salin folder ini dengan isi yang sama ke setiap robot.
