TURTLEBOT3 LINUX MINI QUEST
==========================

Misi:
Temukan file treasure.txt dengan menjelajahi folder menggunakan perintah Linux.

Perintah yang boleh digunakan:
  pwd       - melihat lokasi folder saat ini
  ls        - melihat isi folder
  cd NAMA   - masuk ke folder
  cat FILE  - membaca isi file

Mulai:
  cd ~/treasure_hunt
  ls

Aturan:
1. Jangan gunakan pencarian otomatis seperti find atau locate.
2. Baca petunjuk yang ditemukan dan ikuti arahnya.
3. Jika menemukan treasure.txt, baca isinya dengan cat.
4. Laporkan kode/misi yang tertulis di dalamnya kepada instruktur.

Catatan instruktur:
- Setiap tim sebaiknya memulai dari ~/treasure_hunt.
- Struktur folder dibuat sama untuk semua tim.
- Folder sengaja memakai nama yang umum; peserta perlu membaca petunjuk.
